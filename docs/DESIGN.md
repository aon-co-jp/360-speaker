# 設計案(2026-10-25)

## 1. 音響構造(全方位)

- 各WAYは**円周上に等間隔のリング状に外向きドライバーを配置**(トールボーイ=リングを縦に積む)。
  ドライバー数 n・リング半径は帯域ごとに最適化。高域ほど小径・少数で、リング間隔が波長に対し広がりすぎないようにする。
- 水平面は円対称で均一化、垂直面はリング積層でライン音源的に絞る(床・天井反射を減らす)。
- 初期案(シミュレーターの既定値、5WAY): 
  WAY1(〜150Hz) φ70mm相当×6、WAY2 ×4、WAY3 ×3、WAY4 ×3、WAY5 ×2。分割 150 / 600 / 2.5k / 8kHz、LR4。
- 版の違い: 通常ウーファー版=最低域のWAY1が通常径、スーパーツィーター版=最上WAYが小径(φ12相当)で広帯域化、サブウーファー版=最低域に大径2発を追加。
- 注意点: ドライバーの外向き配置では、隣接ドライバー間の干渉(ローブ)が高域で出る。シミュレーターの橙線(方位間偏差)で確認。

## 2. 構成A: アンプ内蔵

- スピーカー背面に、WAYごとの目盛り付きアナログボリューム + 連動マスター。
- 左右SETで同期させるため、各ボリュームは
  アナログ素子(ステップ式減衰器/抵抗ラダー)+エンコーダ/MCUでの左右連動、のハイブリッドが現実的(下記)。

## 3. 構成B: アンプ無し + オプションのプリアンプ(追加案)

**スピーカー(パッシブ)**
- WAYごとの個別入力端子(バイアンプ/マルチアンプ接続)、サブウーファー端子。
- 各WAYのクロスオーバーは外部(プリ内蔵のアクティブ分割 or パッシブ分割ネットワーク)から選択。
  → パッシブ版は端子を各WAY直結にし、分割はプリ側のアクティブクロスオーバーで行う案が音質・シンプルさの面で有利。
- アンプ・電源を持たないため軽量・低価格・故障要因が少ない。他社パワーアンプも使える。

**プリアンプ(別売)**
- 入力: XLR/RCA。出力: WAYごと×左右(n×2ch)+サブウーファー出力。
- 目盛り付きボリューム: WAY数 n 個(左右連動)+全体マスター1個。
- ボリューム方式は「アナログ信号経路 + デジタル制御(エンコーダ→MCU→減衰IC/リレーラダー)」を推奨。
  左右・WAY間の連動と記憶・リモコンが容易で、目盛りリングはエンコーダ周囲に機械的に付ける。
- 外部アンプ必要出力はシミュレーターで WAY別に表示(目標音圧・能率から概算)。

## 4. 製品ラインの出し分け

1WAY〜5WAY × 3版 = 15 SKU 相当。金型・端子板・ボリュームモジュールを共通化し、
リング段数(WAY数)と中身のドライバーだけで展開する(SKU数の管理が採算の鍵)。

## 5. 受動ネットワーク版の設計図(2026-10-25)

図面は [`out/`](../out/)(`360-speaker-blueprint.pdf` 2ページ、`blueprint1/2` のJPG)。生成は `python docs/gen_blueprint.py`。

- 構成: 1台のアンプ → 5WAYの2次LR(Linkwitz-Riley)パッシブネットワーク(コイル+コンデンサ、分割 100Hz/600Hz/3kHz/12kHz)→ WAYごとのL型アッテネーター(目盛り付きステップ式、定インピーダンス4Ω)→ 対向ユニット2個を並列(8Ω×2=4Ω)。
- L-padをフィルターの**後段(ドライバー側)**に置くので、フィルターから見た負荷は減衰量によらず4Ω一定で、分割周波数が動かない。
- **注意(許容電力)**: L-padは減衰分を抵抗で熱にするため、超低音・低音のWAYでは大電力を扱える無誘導巻線抵抗が必要で、絞るほどアンプの電力が無駄になりダンピングも悪化する。
  別案として「超低音・低音はボリュームを付けず、能率合わせは固定にする」(下記の貼付案)がある。5つのボリューム自体は元の指定どおり残している。
- LC値は単独の理論値。ドライバーのインピーダンス曲線やWAY間の相互作用で変わるため、実測と調整(ゾベル回路等)が必須。

### 代替案: 垂直対向 + 円錐リフレクター(別AIの提案を取り込み)
ユニットを上向き/下向きに対向させ、間に円錐ディフューザーを置いて水平に360°拡散する方式。水平対向(前後)より側面の高域落ちが出にくい一方、高さと反射の設計が難しくなる。
超高音は40kHz以上のリボン/ホーン型(例: FOSTEX T90A系)を候補とする(**仕様は未確認、採用前に公式データで確認**)。次段階でシミュレーターに「垂直対向+リフレクター」モデルを追加して前後対向と比較する。
