# 縦方向の山谷の改善検討(2026-10-25)

目的: 仰角±30°(聴く高さ)での周波数特性のばらつきを減らす。評価は 100Hz〜12kHz の各周波数で、仰角±30°(1.5°刻み41点)の**10〜90パーセンタイル幅**(dB)の最悪値。
狭く深いノッチ(最小値)で評価すると、仰角の刻みを粗くするだけで結果が変わる(初回は3°刻みで見落とした)ため、パーセンタイル幅を採用した。
再現: `cd sim && cargo test --release --test sweep -- --nocapture`(約3.5分)。分割周波数は条件ごとにランダム探索(400回)で最適化。

## 結果(P90−P10、小さいほど均一)

| 条件 | 最良値(dB) | 備考 |
|---|---|---|
| 基準(LR2、隣接バンドを逆極性にしない場合は別) | 15.1 | 分割 60/600/4200/13200 Hz |
| 分割次数 LR2 / LR4 / LR6 / LR8 | 13.2 / 12.5 / 13.2 / 13.3 | 差は小さい |
| WAY3〜5の間隔 ×1 / ×0.7 / ×0.5 | 13.0 / 13.9 / 12.8 | 縮めても改善しない |
| 反射円錐の開口 ×0.5 / ×1 / ×2 / ×3 | 13.4 / 13.3 / 13.5 / 16.2 | ×3(大きすぎ)は悪化 |
| 円錐形状: 直線 / 凸±20° / 凸±40° / 凹±20° | 13.0 / 12.5 / 13.4 / 13.0 | 差なし |
| 開口の周辺漸減(Hann) | 13.4(凸±20°併用 13.3) | 差なし |
| 組合せ(LR6・間隔×0.6・開口×2・凸±20°+Hann) | 11.2 | 最良だが±15°内は16dBと悪化 |

## 分かったこと
1. **LR2(12dB/oct)は隣接バンドが逆相で合成される**。1つおきに極性を反転して配線しないと、分割点で深い谷になる(最初の試算で 38dB → 反転後 25dB、旧指標)。LR4以上は不要。
2. 上表の差は、探索のばらつき(約±1dB)と同程度で**有意とは言えない**。分割次数・間隔・開口・円錐の曲面は、いずれも決定的な改善手段ではない(開口を大きくしすぎると悪化)。
3. 残る山谷は 4.4kHz 付近(WAY3〜4の分割)にある。原因は、ユニットの中心間隔(約170mm)が波長(約78mm)より大きいこと。**波長の半分以下(約40mm)に近づけるのは、ユニット・円錐の寸法上不可能**に近く、幾何の微調整では解決しにくい。
4. 実用上の採用: **LR4(24dB/oct)・直線円錐(最も作りやすい)・間隔と開口は図面のまま**、分割は 150 / 580 / 4,400 / 14,500 Hz。曲面円錐は効果が確認できないため採用しない(試作で再検証する価値はある)。

## 次に有効そうな手
- WAY3・4を同軸(同一中心)にする、または中音と高音の間の分割帯をなくす(4WAY化)など、**ユニットの中心を揃える**構成の比較。
- 実機で垂直指向性を測定し、モデル(面素の指向性・開口)を較正する。

# 追加検討: ユニットの中心を揃える(同軸化・4WAY化)(2026-10-25)

再現: `cd sim && cargo test --release --test coax -- --nocapture`(約1分)。LR4、分割は条件ごとに400回の探索で最適化。指標は上と同じ(P90−P10、仰角±30°)。
「同軸」はユニット中心(開口中心)を同じ高さにする配置(同軸ユニット、または中音の中心に高音を内蔵)で、開口高さはユニットごとの値のまま(実機では1つの反射円錐を共有する)。

| 構成 | P90−P10(dB) | 最悪周波数 |
|---|---|---|
| 5WAY 基準(間隔170/85mm) | 13.1 | 4.6kHz |
| 5WAY 中音+高音を同軸 | **4.0** | 12kHz(帯域端) |
| 5WAY 高音+超高音を同軸 | 13.2 | 4.1kHz |
| 5WAY 3つとも同軸 | **2.3** | 12kHz(帯域端) |
| 4WAY(中音+超高音、間隔255mm) | 12.9 | 6.1kHz |
| 4WAY(中音+超高音、間隔130mm) | 12.1 | 6.7kHz |
| 4WAY(中音+超高音を同軸) | **3.0** | 12kHz(帯域端) |
| 3WAY(低音+同軸[中+超高音]) | **2.1** | 12kHz(帯域端) |
| 5WAY 低音を中音に近接(間隔120mm) | 13.1 | 4.6kHz |

## 分かったこと
1. **縦方向の山谷は、隣り合うWAYの中心が離れていることが原因**で、**同軸化で 13dB → 2〜4dB に大きく減る**(間隔の縮小や4WAY化だけでは12〜13dBのまま)。
2. 効くのは**上側(中音〜超高音)の分割**の同軸化。高音+超高音だけの同軸、または低音側の間隔縮小は効かない(問題は4.4kHz付近の分割だったため)。
3. 同軸化後の最悪点は帯域端(12kHz)で、開口(反射円錐の高さ約33mm)が波長に近づいて指向性が狭くなる影響。これは円錐を低くすれば緩和できる見込み。
4. 画面(`WAY3-5の配置`)で再現可能。ページ側の探索では「中音+高音を同軸」5.7dB(分割 160/343/4217/16000Hz)、「3つとも同軸」2.4dB(81/211/6082/10596Hz)。分割値は探索結果の一例で、実部品に合わせて決め直す。

## 実現性(要確認)
- 「中音+高音の同軸」: 市販の小口径2WAY同軸ユニット(中音の中心にドームを内蔵)を、反射円錐の下に上向きで置く。ただし内蔵ツィーターが中音コーンの音を乱す、反射円錐の頂点とツィーターの干渉が出る、などは**実機でしか分からない**。
- 「3つとも同軸」は3WAY同軸ユニット(高価・種類が少ない)が必要で、現実的には「中音+高音の同軸 + 超高音を近接」が候補。
- 結論(暫定): **推奨構成を「中音+高音の同軸」に更新する価値がある**。実部品の選定と、同軸ユニットを使った試作での垂直指向性測定が次の課題(測定準備は `docs/MEASUREMENT.md`)。
