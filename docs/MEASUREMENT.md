# 実機測定の手順書(試作機の垂直・水平指向性ほか)

目的: シミュレーター(`web/`)の近似モデルを実測で較正し、設計の当否を判断する。
測定データはシミュレーターの「実測データの取り込み・モデル較正」に読み込める(0°基準の相対値で比較、z・開口・角度を自動補正)。

## 1. 準備するもの
- 測定用マイク: 校正データ付きの測定マイク。**超高音(WAY5)は40kHz以上を狙うため、40kHzまで平坦な超広帯域マイクと、サンプリング 96kHz以上(192kHz推奨)のオーディオインターフェース**が必要。一般的なUSBマイクは20kHz付近から落ちるので、超高音帯は測定できないことがある(その場合は20kHzまでで評価し、超高音は別測定と明記する)。
- 測定ソフト: REW(Room EQ Wizard)など。掃引音(スイープ)でインパルス応答を取り、ゲート処理できるもの。
- 回転台(ターンテーブル)またはスピーカーを横倒しにして角度を変えられる治具。マイクスタンド・巻尺・水平器。
- 測定用アンプ(試作ネットワークを駆動)、ダミー抵抗(インピーダンス測定の基準抵抗)。
- 聴力保護: 測定音は大きくなりやすい。耳栓・音量制限を使う。

## 2. 設置(垂直指向性)
縦に長いスピーカーの仰角特性を測るには、**スピーカーを横倒しにして回転台に載せ、回転軸を「WAY3の開口中心(z=約850mm)」に合わせる**。マイクは回転軸と同じ高さ・距離3mに固定する。回転台を回すと、仰角を変えたのと等価になる(水平方向は円対称なので回転方向は問わない)。
- 仰角の符号: **+ は上方向(WAY5側)**。-60°〜+60°を7.5°刻み(最低でも15°刻み)で測る。0°を必ず含める。
- 距離: 3m以上(スピーカーの全長1.1mに対して遠方界に近づける)。床・壁から離れた屋外または大空間が望ましい。
- ゲート: 最初の反射が来る前の時間(例: 床・壁までの経路差/音速)で切り、**6〜8ms程度の窓**にする。この窓では約150Hz以下は信頼できない(それ以下は近接測定や別の方法で補う)。
- 水平指向性: 同様に、スピーカーを縦のまま回転軸に載せ、10°刻みで0〜360°を測る(円対称のはず。目標は各WAY帯域で±1.5dB以内)。

## 3. 測定手順(REWの例)
1. マイクを校正ファイルとともに設定し、測定レベルを合わせる(最大音圧は耳栓の上で、85dB前後から)。
2. 0°で掃引測定→インパルス応答のゲートを設定→周波数特性を確認(電気的ノイズ・歪みも見る)。
3. 回転台を7.5°ずつ回し、同じ設定で測定。**毎回、ファイル名を `el_+7.5.txt`、`el_-15.txt` のように仰角の数値で保存**する(エクスポート: Measurement → Export → Frequency response as text。ヘッダー行は `*` で始まり、その後に `Freq(Hz) SPL(dB) Phase` が並ぶ形式でよい)。
4. 同じ角度を2回測り、**再現性(差が0.5dB以内)**を確認する。
5. `measurement/results-template.csv` に、ファイル名・条件・メモを記録する。

## 4. シミュレーターで較正する
1. `web/index.html`(または公開ページ)の「実測データの取り込み・モデル較正」で、ファイル全部を選択して読み込む(0°が必須)。
2. 実測とモデルの差(RMS)と、実測のばらつき(P90−P10)が表示される。
3. 「モデルを較正」でz・開口・角度のずれを推定する(較正前後のRMSが出る)。推定値が現実の寸法ずれと合わない場合は、モデル自体の仮定(面素の指向性、開口)の見直しが必要。
4. 較正済みのモデルで、反射円錐・隙間・同軸化などの比較をやり直す。

## 5. 他の測定項目
| 項目 | 方法 | 目安・判断 |
|---|---|---|
| インピーダンス | REWのインピーダンス測定(基準抵抗)。WAYごとにL-pad前後・ネットワーク込みで測る | ネットワーク設計の想定(WAY1・2=4Ω, WAY3〜5=8Ω)との差を記録し、ゾベル回路・L-padを調整 |
| T/Sパラメーター | 各ユニット単体を空中で(質量付加法)または既知容積の箱で測定 | シミュレーターの仮定値を実測値に置き換える |
| スリット/縁の風切り音 | 近接(スリット出口から数cm)で音圧・歪み(THD)を40/60/100Hz(WAY1)・主要帯域(WAY3〜5)で測り、聴感でも確認 | 風速が20m/sを超える条件で歪みが急増するか(シミュレーターの風速評価の検証) |
| 壁の振動 | 加速度計(またはスマートフォンの加速度アプリ)を壁面・円錐の支柱に当て、低域で掃引 | 壁のたわみ・共振の確認 |
| 円錐支柱の共振 | 支柱を軽く叩いた応答、または掃引で測定 | 支柱が音を乱していないか |
| 全高調波歪み | 1mで90dB/100dB等の条件、帯域ごとに | 製品の仕様値のために記録 |

## 6. 受け入れ基準(案・要検討)
- 垂直指向性: 仰角±30°、100Hz〜12kHzで**P90−P10が6dB以下**(シミュレーターは中音+高音の同軸で約4〜6dBと予測)。
- 水平指向性: 各WAYの帯域で全方位が±1.5dB以内。
- 風切り音・歪み: 指定の最大音圧までスリット・縁の風切り音が聴取されず、THD規定値以内。
- 上記は暫定案。市販品としての仕様は、競合比較と試作結果で決める。

## 7. 試作マトリクス
`measurement/test-matrix.csv` に、反射円錐(角度・隙間・半径・形状)、スリット隙間、同軸/別々、ネットワーク次数などの比較条件を一覧にした。1つずつ変えて、同じ手順で測る。
